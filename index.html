Enhancing Signal Purity with Artificial Intelligence in X-band telescopes
ESPAI advances the understanding of signal purity using Artificial Intelligence to generate synthetic datasets, enable automated Anomaly Detection of celestial disturbance, and provide open, scalable tools for the era of Big Data in astronomy.

About the ESPAI Project

The ESPAI project leverages advanced machine learning algorithms to optimize signal purity within X-band radio astronomy. The project's primary objective is to develop an autonomous framework capable of mitigating celestial interference found in observational data. By refining the filtering mechanisms used to clean these observations, ESPAI intends to minimize data loss during analyses and significantly elevate the precision of subsequent scientific analyses.

To address these challenges, ESPAI integrates Generative AI to produce a large dataset of synthetic observations of celestial disturbances. An anomaly detection system is developed to identify and remove celestial disturbances from X-band telescope signals, with the potential for real-time implementation to reduce data storage requirements. The system is designed to be adaptable to the specific needs of each telescope, allowing customization based on geographic location and particular disturbances.

The project delivers openly accessible tools: curated datasets, generative frameworks, parameter-recovery algorithms, and source code repositories, all provided under transparent licensing terms. In this way, ESPAI contributes to reproducible science and accelerates discovery for both the astrophysics and AI communities.

🧠 AI for Celestial disturbances

Development of an innovative Generative AI framework to generate a large dataset of celestial signals free from disturbances, which will subsequently be shared with the international scientific community.

🔍 Anomaly Detection System

Design of a cutting-edge Machine Learning model, utilizing Anomaly Detection techniques, for identifying and removing celestial disturbances from astronomical signals.

⚙️ Parametric System for Personalisation

Implementation of a flexible parametric system that allows customization of models according to specific disturbance signals detected by telescopes, adaptable to diverse scenarios and tailored to each telescope’s geographic location.

Project outputs

  • Synthetic datasets: High-fidelity event sequences generated from optimized Variational Autoencoder (VAE) models. Each sample includes relevant photon properties (energy, position) and metadata, derived from XMM-Newton observations, providing a realistic and reliable resource for astrophysical studies and model training.
  • Inference and classification tools: Multi-Layer Perceptron (MLP) classifiers that distinguish solar flare photons from signal photons within Bad Time Intervals (BTIs). They are robust to data degradation (e.g., cheesing holes, dead columns) and utilize advanced feature engineering like spatial and spatio-temporal photon density.

Validation & benchmarking

Consistency checks against Good Time Intervals (GTIs) using energy spectrum analysis. Performance reporting focuses on statistical validation using the Pearson correlation coefficient and Kolmogorov-Smirnov (K-S) tests to ensure the classified signal distributions match physical expectations.

Methodology at a glance

A unified pipeline links (i) data pre-processing using "cheesing" to remove astrophysical sources, (ii) controlled synthetic data generation via VAEs, and (iii) robust classification of disturbances using MLPs with data augmentation. The workflow supports observation-based inference constraints and scales to handle large blank-sky datasets.
