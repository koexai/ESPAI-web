ESPAI

Enhancing Signal Purity with Artificial Intelligence in X-band telescopes
ESPAI is a machine learning framework that enhances the signal purity of X-ray observations. It uses Artificial Intelligence both to generate synthetic flare datasets and to automatically classify events in XMM-Newton's contaminated segments (Bad Time Intervals). It provides open, scalable tools designed for the era of Big Data in astronomy.
ESPAI has been selected and funded under the ICSC – Centro Nazionale di Ricerca in HPC, Big Data e Quantum Computing, as part of the PNRR, and supported by the European Union – NextGenerationEU.

About the ESPAI Project

The ESPAI project leverages advanced machine learning algorithms to increase signal purity within X-band radio astronomy. The project's primary objective is to develop an autonomous framework capable of mitigating celestial interference found in observational data of XMM-Newton radiotelescope. By refining the filtering mechanisms used to clean these observations, ESPAI intends to minimize data loss during analyses and significantly elevate the precision of subsequent scientific analyses.

To address these challenges, ESPAI integrates Generative AI to produce a large dataset of synthetic solar flare events. A classification system is developed to identify and remove solar flare from X-band telescope signals, with the potential for real-time implementation to reduce data storage requirements.

The project delivers openly accessible tools: curated datasets, generative frameworks and source code repositories, all provided under transparent licensing terms. In this way, ESPAI contributes to reproducible science and accelerates discovery for both the astrophysics and AI communities.

🧠 AI for Celestial disturbances

Development of an innovative Generative AI framework to generate a large dataset of celestial signals free from disturbances, which will subsequently be shared with the international scientific community.

🔍 Anomaly Detection System

Design of a cutting-edge Machine Learning model, utilizing Anomaly Detection techniques, for identifying and removing celestial disturbances from astronomical signals.

Project outputs

  • Synthetic datasets: High-fidelity event sequences generated from optimized Variational Autoencoder (VAE) models. Each sample includes relevant photon properties (energy, position) and metadata, derived from XMM-Newton observations, providing a realistic and reliable resource for astrophysical studies and model training.
  • Inference and classification tools: Multi-Layer Perceptron (MLP) classifiers that distinguish solar flare photons from signal photons within Bad Time Intervals (BTIs). They are robust to data degradation (e.g., cheesing holes, dead columns) and utilize advanced feature engineering like spatial and spatio-temporal photon density.

Validation & benchmarking

Consistency checks of the predicted results on the Good Time Intervals (GTIs) using energy spectrum analysis. Performance reporting focuses on statistical validation using the Kolmogorov-Smirnov (K-S) test to ensure the classified signal distributions match physical expectations.

Methodology at a glance

A unified pipeline links (i) data pre-processing using XMM-Scientific Analysis System (SAS), including cheesing task to remove astrophysical sources, (ii) controlled synthetic data generation via VAEs, and (iii) robust classification of disturbances using MLPs with data augmentation. The workflow supports observation-based inference constraints and scales to handle the large Blank Sky dataset.
